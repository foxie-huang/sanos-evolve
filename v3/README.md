# v3 — the kernel engine

The v2 engine discretised the two volatility factors onto Gauss–Hermite abscissas and propagated by
matrix powers. This one carries the factors **continuously** and integrates them in closed form. The
calibration targets and the SANOS static layer are unchanged in spirit; what changed is the
propagation, the forward-variance readout, and — for off-index work — the target construction.

| | v2 | v3 |
|---|---|---|
| factors | discrete abscissas (`n_F`, `n_S`) | continuous AR(1), closed-form step law |
| resolution protocol | two-stage node ladder, coarse → fine | one fixed setting; sensitivity measured |
| forward-variance readout | unlevered | leveraged (`VOVLEV=1`) |
| device | CPU | MPS/CUDA, bit-deterministic |

## Layout

    kernel_fast/   the engine: kernel build, propagation, recompression, readouts, the fitter
    sanos/         the SANOS static layer and its exact-martingale overlay
    diagnostics/   target construction and validation, mostly off-index
    figures/       the standard SSR / forward-variance panels

## Data

Two roots, neither in the repository, both by environment variable:

* `ORATS_EOD_DIR` — the licensed ORATS EOD option chains (see the repository README).
* `SANOS_V3_DATA` — calibration **output**: per-date fit records, the SANOS LP cache, the frozen
  static layer, panel records. Regenerated by running the pipeline; defaults to `v3_data/`.

## Running a panel

    export ORATS_EOD_DIR=/path/to/orats_eod SANOS_V3_DATA=/path/to/outputs
    cd v3/kernel_fast
    DEV=mps LADDER=42 VOVLAMTEN=avg KAPS_FREE=1 PIN=rho_s=0 BOX="nu_l=0.1,3.0" \
      TAG=_n9 python3 refit.py 2019-06-03

Off index, with the corrected realised target:

    python3 ../diagnostics/ndx_vov_cm.py            # constant-maturity strip
    python3 ../diagnostics/ndx_bracket_churn.py     # bracketing-expiry changes
    python3 ../diagnostics/ndx_vov_screen.py        # bound + splice + churn removal
    python3 ../diagnostics/spx_pq_vov.py            # the observation-operator ratio
    DEV=mps TICKER=NDX NDXVOVSCR=1 NDXVOVPQ=1 SEW=1 \
      NDXTENORS=14,21,30,45,60,90,120,180 LADDER=42 VOVLAMTEN=avg KAPS_FREE=1 \
      PIN=rho_s=0 BOX="nu_l=0.1,3.0" TAG=_c9 python3 refit.py 2019-06-03

## Reproducibility

Fit records carry their own configuration and targets, so a panel is reconstructable from the records
plus the chains. `kernel_fast/backfill_provenance.py` verifies a record's target series by
reconstructing it from the caches rather than trusting the recorded flags.
